# 持续跟踪第一版：使用与实现记录

日期：2026-09-13。基于总体架构实现的第一版量价闭环，不等同于全部目标架构已完成。此页保留历史实现记录；当前长期跟踪规则见 [LONG_TERM_TRACKING.md](LONG_TERM_TRACKING.md)，已取消固定的每日 24 次上限。

## 使用

双击项目根目录 `Trading_Terminal.exe`。在顶部打开“持续跟踪”，点击“关注 ZEC”，或选择品种及研究周期后开启。跟踪周期独立于当前图表，默认 15 分钟。卡片可暂停/恢复、查看研究记录和保存研究方向。已有开启任务会在启动后恢复；主动暂停的任务保持关闭。

- 绿灯：数据与研究执行器正常，任务处于研究、验证或等待。
- 黄灯：首次研究、恢复复盘、数据缺口、执行器离线或调用上限。恢复研究未完成前不会变绿。
- 红灯：主动暂停。

聊天与自动研究使用独立会话。聊天发送时附带该标的最近研究摘要；若要改变后台研究方向，在跟踪卡片中保存备注。聊天内容不会未经确认自动改写任务目标。

## 实际默认规则

| 项目 | 第一版配置 |
|---|---|
| 行情检测 | 每 30 秒轮询 Bitget REST；不等于逐笔行情 |
| 指标 | 五类已安装 Skill 的计算代码，使用任务自己的数据；只用已收盘 K 线 |
| 模型 | dsh 的 DeepSeek 官方 provider，优先 flash/chat 模型；复用本地已有密钥 |
| 价格变化 | 相对上次研究收盘价变化至少 0.8% |
| 量能变化 | 最新已收盘量 / 前 20 根平均量至少 2 倍 |
| 价位条件 | 研究输出经验证的上/下观察价位；只接受相对当前价格合理的方向与范围 |
| 持续验证 | 初始或恢复研究后观察两个研究周期；有新收盘 K 线才重新研究 |
| 定时复查 | 每小时；同时要求有尚未研究的新收盘 K 线 |
| 冷却 | 自动触发研究至少间隔 15 分钟；初始/恢复单独处理 |
| 研究次数 | 每任务每日最多 24 次，UTC 日切换；失败尝试也计数 |
| 单轮限制 | 8 分钟执行超时，10 分钟任务租约，上下文最多 60,000 字符 |
| 失败处理 | 退避重试；连续失败三次后每小时再试，始终受日上限约束 |
| 任务数 | 最多 20 个独立标的任务 |

这不是货币金额的硬预算：模型价格、单次输出与服务内部重试会影响实际费用。规则目前是第一版固定值；研究周期和研究方向可在界面调整。

## 数据与恢复

`tracking.sqlite3` 与原市场采集数据库分开保存。任务记录开启意图、配置代次、最后行情与最后完成研究的双断点。结果提交校验代次和租约，暂停、修改方向、改周期后旧结果不能覆盖新状态。

恢复从尚未研究的区间开始，而不是只看最新 300 根 K 线。Bitget v3 `history-candles` 每页最多取 100 根，每轮最多回补三页；未齐时保持黄色，后续继续。对长区间生成最多 20 段摘要，保留最高/最低、开收、总量与最大量时间，再结合最近窗口进行研究。

实际接口检查确认：历史查询 endTime 使用缺失 K 线的下一周期边界；减一毫秒会漏掉边界 K 线。接口依据：[Bitget 市场数据文档](https://www.bitget.com/docs/catalog/market/market-data)，并经过真实接口测试。

## 记忆

- 当前研究状态：最近结论、依据、方向和失效条件。
- 研究事件：独立记录与对应上下文，可按 ID 追溯。
- 最近历史：任务只保留 12 条紧凑索引，每轮载入最近 4 条。
- 日级索引：程序整理当天最新判断、方向序列与原始记录 ID，每轮最多载入最近 3 天索引。这是可追溯的阶段索引，不宣称完整语义总结。
- 最近行情：每轮原始 K 线最多提供 60 根；完整近期窗口用于 Skill 计算，长缺口使用分段统计。
- 清理：成功研究后清理已研究且超过 90 天的原始行情，以及超过 30 天的结束任务日志。研究证据和 dsh 会话记录仍保留，磁盘归档策略还可进一步完善。

## 架构边界

LangGraph 编排采集/恢复和评估/入队节点，SQLite 事务负责耐久状态与提交一致性。dsh 主进程的单 worker 按租约执行独立研究，并定期确认任务仍开启。专用 preset 不授予工具，所有量价计算在可信程序侧完成，避免模型重复采集当前屏幕的错误标的。

因此第一版自动研究聚焦 Bitget 量价，不自动搜索或完整回补新闻；新闻、资金费率、持仓量与多周期联合研究仍属后续扩展。普通对话保留原有工具能力。

桌面进程关闭后模型研究停止；后台可能继续采集。重新打开时检测 worker 中断并执行恢复。电脑关机或休眠期间不会执行，不能视作云端全天候服务。

通知目前显示在终端状态栏与研究记录中，并按研究 ID 去重；尚未接入系统推送或手机消息。第一版未执行任何交易。

## 验证记录

- 真 Bitget：ZECUSDT 15m 初始数据、五类 Skill 结果，以及 400 根 K 线恢复区间连续性。
- 真 DeepSeek：独立 preset 会话成功产出结构化研究，保存记录并进入绿灯验证状态。
- 真重启：保留上次判断，补充新增已收盘行情并产出恢复研究。
- 真暂停重启：保持红灯；再次开启先黄灯恢复。
- UI：1280px 宽窗口无页面横向溢出，跟踪卡片与状态可见。
- 自动测试：暂停竞争、重复提交、超时结果、断线恢复、行情缺口、价格触发、日上限、形成中 K 线排除、API 认证和输入验证。

源码入口：`src/market_monitor/tracking.py`、`vendor/deepseek-harness/apps/desktop/src/tracking-worker.ts`、`desktop/presets/market-research/`。
